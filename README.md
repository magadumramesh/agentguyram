# agentguyram

The working repo for the [@agentguyram](https://instagram.com/agentguyram) Instagram channel: AI agents, actually working.

- [`strategy/growth-plan-250-to-10k.md`](strategy/growth-plan-250-to-10k.md): 90-day plan to grow from 250 to 10K followers (Sep 28 – Dec 27, 2026)
- [`strategy/weekly-tracker.md`](strategy/weekly-tracker.md): weekly metrics log
- [`content/CALENDAR.md`](content/CALENDAR.md): all 91 posts, day by day. Each folder has a `post.md` with the script or slide copy, caption, hashtags, first comment, cover brief and Stories.
- [`content/RECORDING.md`](content/RECORDING.md): everything you need to film, batched by week
- [`starter-kit/`](starter-kit/README.md): the free Agent Starter Kit sent to people who comment AGENT

Rendered post assets live in [`agentguyram-media`](https://github.com/magadumramesh/agentguyram-media).
