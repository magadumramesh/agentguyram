# Agent Advent: 24 upgrades for your AI coding agent

One a day, Dec 1–24, 2026. Each takes under 5 minutes to set up.

## It checks itself
1. **Audit your CLAUDE.md.** Run every command in it, check every folder exists, and cut stale lines.
2. **Questions first.** "Ask me up to 5 questions first, only ones that would change what you build."
3. **Name the file and function.** Point, don't describe.
4. **One `check` command.** `lint && typecheck && test`, and "run it before saying done" in CLAUDE.md.
5. **Commit after every green step.** Your save button.
6. *(Week 1 recap)*

## It knows your team
7. **A fresh branch per task.** A free undo button.
8. **A decisions log.** Corrected it twice? That's a decision. Log it.
9. **"Do it like this file."** Reference files beat style guides.
10. **A domain glossary.** "Archived: hidden, restorable, NOT deleted."
11. **Two options before one answer.** Choose, don't just accept.
12. **Agent-written PR descriptions.** What changed · why · how to test · what's risky.
13. *(Week 2 recap)*

## You stay in control
14. **Corrections become rules.** "Add a rule to CLAUDE.md so you don't do this again."
15. **A personal CLAUDE.md.** Your preferences, across every project.
16. **Know your undo.** Git + your tool's rewind. Practise once.
17. **Connect one MCP server.** The tool you alt-tab to most. Read-only first.
18. **Test your setup.** Agent vs Me: time a real bug.
19. **Review the diff, not the chat.** The summary is a story; the diff is the truth.
20. *(Week 3 recap)*

## Wisdom
21. **Tests before touching old code.** Capture current behaviour, then refactor.
22. **Score your setup out of 10.** See the list below.
23. **Know when NOT to use an agent.** One-liners, fuzzy ideas, learning.
24. **This list.**

## Setup scorecard (Day 22)
1. CLAUDE.md with working commands · 2. A spec on every real task · 3. Plan before multi-file changes · 4. One check command · 5. Branch + commit on green · 6. A subagent · 7. A Skill / custom command · 8. A hook · 9. An allowlist with .env denied · 10. You read the diff
