# 91 days of content (Sep 28 – Dec 27, 2026)

There's one folder per day, named `Month D - Weekday - Title` so it drops straight into the AgentGuyRam folder on the Mac. Each folder has a `post.md` with the full script or slide copy, caption, hashtags, first comment, cover brief and Stories.

- **[CALENDAR.md](CALENDAR.md)** lists every day in date order, with what you need to do for each post.
- **[RECORDING.md](RECORDING.md)** is a batch list: everything to film, grouped by weekend session.

**Saturday remix rule.** If a post that week hit **3x your median reach**, replace Saturday's script with a remix of it (new hook, same idea). The written Saturday script moves to the backlog.

## Before posting any post (from the brand kit QA gate)
1. **Fact-check** every product claim against the current docs *that day*. Tools change fast. Put the sources in the first comment.
2. Build visuals with the **current standard** (`agr.py` / `reelpanel.py`, identity block top-right, covers with an illustration). Use the dark kit unless you ask for light.
3. Anything illustrative on a slide (a file, a snippet) is labelled "example".
4. **Series numbers** (ACE Day, Anatomy Part) are my best guess from the media repo, where ACE was at Day 9 on Sep 23 and Anatomy at Part 2 on Sep 22. Adjust them if your latest numbers differ.
5. **Post numbers** are written as `post[N]`. Assign the next free number from your Mac folder, because the media repo only shows up to post40 and the skills mention post46.
