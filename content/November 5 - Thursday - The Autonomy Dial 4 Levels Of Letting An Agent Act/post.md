**S2 · The framework**

- Visual: blast-radius circles, small → large
- Body: "Small, reversible → turn it up. Big, irreversible → turn it down."

**S3 · L1 SUGGEST**
- Body: It proposes; you do it. Plan mode lives here.
- Use for: architecture, anything touching money or data.

**S4 · L2 ASK FIRST**
- Body: It acts, but asks before each risky step.
- Use for: unfamiliar code, new repos.

**S5 · L3 ACT + REPORT**
- Body: It acts within an allowlist and shows you the diff.
- Use for: features on a branch with tests.

**S6 · L4 ACT ALONE**
- Body: It runs unattended and opens a PR.
- Use for: small, well-tested, easy-to-revert jobs (dependency bumps, lint fixes).
- Without limits: "I let it run alone on a vague task. Never again."

**S7 · Cheat sheet**
| Task | Blast radius | Level |
|---|---|---|
| DB migration | Huge, irreversible | L1 |
| New repo exploration | Unknown | L2 |
| Feature on a branch w/ tests | Contained | L3 |
| Lint fixes, dep bumps | Tiny, revertible | L4 |

## Caption
"Should I let the AI agent do it?" is the wrong question. Ask: which level?

My autonomy dial:
L1 SUGGEST: it proposes, you act (migrations, money, data)
L2 ASK FIRST: it asks before each risky step (unfamiliar code)
L3 ACT + REPORT: it acts within an allowlist and shows the diff (features on a branch)
L4 ACT ALONE: unattended, opens a PR (tiny, revertible jobs)

Match the level to the blast radius. Small and reversible: turn it up. Big and permanent: turn it down.
