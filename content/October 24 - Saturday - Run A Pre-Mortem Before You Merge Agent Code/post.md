## Caption
Before every big launch at work, we run a pre-mortem: "It's a week from now and this failed. Why?"

Now I make my AI agent do it before every merge.

Ask "is this good?" and it says yes. Ask "it's next week and this broke in production, what happened?" and it lists the holes: race conditions, empty states, the user with 10,000 rows.

Fix the top two. Then merge.

Don't ask your agent if it's right. Ask it how it'll fail.

Send this to your team lead.
