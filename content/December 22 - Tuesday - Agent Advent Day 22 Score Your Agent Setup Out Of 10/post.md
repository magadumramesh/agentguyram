**S2 · Points 1–5** (checklist)
1. ☐ CLAUDE.md with commands that actually work
2. ☐ A spec (goal + done when) on every non-trivial task
3. ☐ Plan before code for multi-file changes
4. ☐ One `check` command the agent runs before "done"
5. ☐ Fresh branch per task, commit on green

**S3 · Points 6–10** (checklist)
6. ☐ At least one subagent (e.g. a reviewer)
7. ☐ At least one Skill or custom command
8. ☐ At least one hook (e.g. format on edit)
9. ☐ A permissions allowlist, with .env denied
10. ☐ You read the diff before every merge
