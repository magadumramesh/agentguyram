**S2 · BEFORE** (checklist)
- ☐ Fresh branch (and `/clear` if reusing a session)
- ☐ 5-line spec: goal · context · done when · not doing · check by
- ☐ Plan mode on for anything touching 2+ files
- ☐ Right model for the job (deep to plan, fast to do)

**S3 · DURING** (checklist)
- ☐ One session, one outcome (new ideas go to TODO.md)
- ☐ Tests first where you can
- ☐ It reads the logs itself (don't paste)
- ☐ Two strikes → note → /clear → fresh start

**S4 · AFTER** (checklist)
- ☐ Tests run, with output shown
- ☐ "What are you not sure about?"
- ☐ Pre-mortem: "how will this fail in prod?"
- ☐ Read the diff, not the chat
- ☐ Commit, then correct the rules (CLAUDE.md) if you repeated yourself

**S5 · The 3 that matter most**
- Headline: "If you only do three: spec, plan, read the diff."
