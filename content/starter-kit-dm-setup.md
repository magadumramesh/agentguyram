# Setting up "Comment AGENT" → DM

Do this before **Mon Oct 5**, the first post with the AGENT CTA.

1. **Host the kit somewhere public.** Pick one:
   - Make this repo (or just `starter-kit/`) public on GitHub, and link straight to `starter-kit/README.md`.
   - Or build a simple landing page, e.g. with the `agent-guy-ram-article-page` skill, and link to it from there.
2. **Set up the auto-DM** with a comment-to-DM tool that works with Instagram's official API (ManyChat is the common one):
   - Trigger: a comment containing `AGENT` (any case) on any post or Reel.
   - Public reply (optional; vary it so it doesn't look spammy): "Sent! Check your DMs 📩"
   - DM message:
     > Here's the Agent Starter Kit 👇
     > [link]
     > CLAUDE.md template, 5-line task spec, 3 subagents, a Skill, a hooks + permissions config.
     > Start with the CLAUDE.md template, it takes 10 minutes. Reply and tell me what you're building 🙌
   - Optionally require a follow before sending the link. It helps growth, but some people find it pushy, so test both.
3. **Test it** from a second account before Oct 5.
4. **Put the link in your bio.**
5. **Reply by hand** to anyone who answers the DM with what they're building. That two-way conversation is a ranking signal, and it's where your best content ideas will come from.
