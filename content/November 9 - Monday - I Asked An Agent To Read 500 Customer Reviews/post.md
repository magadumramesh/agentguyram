## The prompt (for the kit)
```
Read reviews.csv. Cluster the reviews into 5–8 themes.
For each theme: a name, the count, % of total, and 3 verbatim quotes (with row numbers).
Then: the top 3 themes by frequency, and 1 theme that's rare but intense.
Don't invent quotes. If a review is ambiguous, put it in "Unclear".
```
